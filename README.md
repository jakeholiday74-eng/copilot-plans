## Usage

### Load Free Tier Plan

```json
{
  "planId": "free-tier-full-access",
  "agentId": "free-pro-agent",
  "accessLevel": "full",
  "features": "all",
  "limits": "none"
}
```

### Initialize Agent

```json
{
  "agent": "free-pro-agent",
  "capabilities": "all",
  "permissions": "admin",
  "integrations": "enabled"
}
```

## Getting Started

1. Clone this repository
2. Load `plans/free-tier.json` for plan configuration
3. Load `agents/free-pro-agent.json` for agent initialization
4. Validate against `schemas/plan-schema.json`
5. Deploy and activate the free tier
